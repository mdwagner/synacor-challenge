# Synacor Challenge Debugger (REPL)

Start the debugger with the --debug/-x flag. Optionally preload one or more
save files (input is fed to the VM before STDIN takes over):

  ./bin/synacor_challenge --debug
  ./bin/synacor_challenge --debug --load instructions/save2.txt

Commands are matched exactly unless shown with arguments (e.g. "b! <addr>").

## Session control
- "exit" / "quit" / "q": leave the debugger and end the program
- "resume" / "go": leave the REPL and let the VM run normally from the current
  PC. Remaining preloaded input is consumed first, then input falls back to
  STDIN, so the game continues interactively.

## Stepping
- "s" / "stepi": execute the next instruction and stop
- "n" / "nexti": like stepi, but step OVER a `call` (run until it returns)
- "o" / "stepo": step OUT — run to the next `ret`, then execute it
- "sprs": stepi, then print disassembly + registers + stack
- "nprs": nexti, then print disassembly + registers + stack

## Running
- "c" / "continue": run until a breakpoint is hit
- "cp": continue, then print the VM output buffer

## Breakpoints
- "b": print all breakpoints
- "b! <addr>": set a breakpoint at memory address <addr>
- "bd! <addr>": delete the breakpoint at <addr>

## Inspecting state
- "asm": disassemble the instruction at the current PC
- "asm! <pc>": disassemble the instruction at address <pc>
- "reg": print the registers
- "stk": print the stack (top -> bottom)

## VM input / output
- "in": print the entire preloaded VM input buffer
- "@in": print the current input position and the next bytes from it
- "in! <text>": append <text> + newline to the VM input buffer
- "p" / "print": print the accumulated VM output buffer
- "clear": clear the VM output buffer

## Direct execution
- "i! <op> <arg?> <arg?> <arg?>": execute a single opcode directly.
  <op> is the numeric opcode; registers are encoded as 32768-32775 ($0-$7).
  Examples:
    set $7 = 25734   ->  i! 1 32775 25734   (set: op 1)
    mult $3 2 3456   ->  i! 10 32771 2 3456 (mult: op 10)
    push 5           ->  i! 2 5             (push: op 2)

## Puzzle solvers
- "$coin": print the solved coin-slot ordering ("use <coin> coin" lines)
- "$teleporter": brute-force register 7 for the teleporter check and print it
  (the parameterized Ackermann confirmation at 6027; slow, ~100s)
- "$fix_teleporter": instantly set $7 = 25734 and patch the confirmation
  routine at 6027 to `set $0 6; ret` so `use teleporter` succeeds without
  running the (far too deep) real recursion
